# C++ Interview Handbook

**Live page:** https://srisairevanth.github.io/cpp-interview-handbook/

A single-page revision guide for C++ and DSA interviews, in the order to revise it:

- 46 sections — compilation and types, pointers and strings, OOP and vtables, copy/move and the rule of 0/3/5, memory and undefined behaviour, smart pointers, exceptions, templates and concepts, STL containers and internals, algorithms, lambdas, modern C++ up to C++26, threads and atomics, build tools, OS concepts, design patterns and low-level design
- A full DSA part — complexity, the C++ DSA toolkit, arrays and hashing, two pointers and sliding window, sorting and binary search, string algorithms, linked lists, stacks and monotonic structures, backtracking, trees, heaps and greedy, graphs, dynamic programming, tries, segment and Fenwick trees, bits and math — each with tested C++ templates and a must-do problem list
- 511 interview questions with answers (turn on **Quiz mode** to hide them while you revise)
- 73 predict-the-output puzzles and 335 code samples, all compiled and run with g++ 13 (`-std=c++20`, AddressSanitizer and UBSan on)
- 325 LeetCode problems with tick boxes, practice sets (core, hard, online-test, design and concurrency), 12 timed mock rounds, where to practise, and a 21-day plan with a cheat sheet

Open `index.html` in any browser or use the live link. Revision progress, quiz mode and solved problems are saved in your browser.
